# Audi Car Sales Dashboard – Power BI

##Project Overview

Developed an interactive Audi Car Sales Dashboard using Microsoft Power BI to analyze car prices, models, mileage, fuel types, transmission, and sales trends.

## Objectives

* Analyze Audi car prices and models.
* Compare fuel and transmission types.
* Understand mileage and engine size patterns.
* Identify year-wise pricing trends.
* Present insights through interactive visualizations.

## Tools Used

* Microsoft Power BI
* Microsoft Excel
* CSV Dataset

## Key Features

* Interactive dashboard
* Car price analysis
* Model-wise comparison
* Fuel type and transmission analysis
* Year-wise trends
* Data visualization

## Dataset

The project uses an Audi car dataset containing 10,668 records and 9 columns.

## Project Files

* `AUDI Dashboard.pbix` – Power BI dashboard.
* `audi.csv` – Dataset.
